# نوبي — النسخة المستقلة

هذه النسخة لا تعتمد على Manus أثناء تشغيل الزوار. تحتوي على خادم Express مستقل، قاعدة SQLite محلية، جلسات وحسابات خاصة بالموقع، لوحة إدارة، وإعلانات قابلة للربط بـ AdSense أو إعلان داخلي.

## التشغيل السريع

```bash
cp .env.example .env
# غيّر ADMIN_EMAIL و ADMIN_PASSWORD
npm install
npm start
```

ثم افتح `http://localhost:3000`، ولوحة المشغل في `http://localhost:3000/admin.html`.

## Docker

```bash
cp .env.example .env
# عدّل بيانات المشغل قبل التشغيل
docker compose up -d --build
```

قاعدة البيانات تحفظ في volume باسم `noby_data`، ولا تضيع عند إعادة تشغيل الحاوية. النسخ الاحتياطي:

```bash
docker compose cp noby:/app/data/noby.sqlite ./noby-backup.sqlite
```

## الإعلانات

الموقع يعرض إعلانًا داخليًا آمنًا افتراضيًا في الرئيسية وبين الأعمال وأسفل القارئ، ويسجل المشاهدات والنقرات في قاعدة الموقع. لتفعيل AdSense، استخدم معرّف الناشر ومواقع الإعلانات التي وافقت عليها الشبكة، ثم اضبطها من لوحة الإدارة. لا تضع أسرارًا أو معرّفات وهمية.

## الاستقلال والصلاحيات

- الزوار يستخدمون حسابات نوبي الخاصة؛ لا يوجد تسجيل Manus للزوار.
- قاعدة البيانات محلية للمشروع وتنتقل مع Docker volume.
- لوحة الإدارة محمية ببريد وكلمة مرور مستقلين.
- كلمات المرور تُخزن بتشفير bcrypt.
- توجد حماية Helmet وRate Limiting واستعلامات SQLite مُعلّمة.
- القارئ يحمّل مصفوفة صفحات الفصل من قاعدة البيانات في وضع عمودي أو أفقي، ويحفظ آخر صفحة محليًا وللمستخدم المسجل.
- استعادة كلمة المرور تستخدم رمزًا عشوائيًا من 6 أرقام صالحًا 15 دقيقة. في الإنتاج يجب ضبط SMTP؛ وضع `RESET_OTP_DEV_MODE` للاختبار المحلي فقط.
- لا تضع محتوى إلا إذا كان لديك تصريح أو رخصة واضحة؛ شبكة الإعلانات قد ترفض المحتوى غير المصرح به.

## المحتوى

من لوحة الإدارة أضف العمل ثم أضف فصلًا بروابط صفحات مرخصة ونص عربي معتمد اختياريًا. يمكن توصيل OCR/الترجمة لاحقًا بمفتاح مزودك أنت؛ النسخة المستقلة لا تستخدم مفاتيح Manus ولا تفترضها.

## عامل الإدخال الآلي

شغّل `node worker/pipeline.js --url https://example.org/work --license-confirmed --license-url https://example.org/license` بعد ضبط `INGEST_ALLOWLIST`. العامل يقبل صفحات عامة مصرحًا بها، يستخرج البيانات والصفحات، يرفض الشبكات الخاصة والنطاقات غير المسموحة، ويمكنه استخدام مزود OpenAI-compatible مستقل عبر `OPENAI_API_KEY` و`OPENAI_API_BASE` لتنظيف النص والترجمة ومراجعة النتيجة ثلاث جولات قبل إدخالها إلى `noby.sqlite`.

## التشغيل الذاتي والنسخ الاحتياطي

- عند تشغيل الخادم ينشئ نسخة احتياطية أولية، ثم نسخة كل 24 ساعة داخل `data/backups`، مع الاحتفاظ بآخر 15 نسخة.
- يقرأ `INGEST_SOURCES` بصيغة `URL|LICENSE_URL|MANGA_ID|CHAPTER_NUMBER` ويشغّل الإدخال المرخص كل 6 ساعات. لا يبدأ السحب ما لم يكن النطاق موجودًا في `INGEST_ALLOWLIST`.
- `SCHEDULER_RUN_ON_START=true` يشغّل دورة الإدخال عند الإقلاع، وإلا تبدأ الدورة المجدولة بعد 6 ساعات.
- Docker مضبوط على `restart: always` ويحتوي على `HEALTHCHECK`، لكن يلزم تشغيل Docker على جهاز مستمر ومراقبة مساحة القرص.
- يرسل الخادم `journal_mode=WAL` و`synchronous=NORMAL` عند الإقلاع. هذا الإصدار يستخدم `sql.js` المحمول الذي يعيد تصدير ملف SQLite ذرياً، لذلك لا يدّعي وجود ملف `-wal` أصلي مثل محرك SQLite native. للوصول إلى تزامن آلاف الكتابات يلزم نقل طبقة التخزين إلى SQLite native أو PostgreSQL قبل الإنتاج عالي الضغط؛ النسخة الحالية مناسبة للتشغيل المستقل منخفض/متوسط الكتابات مع النسخ الذري.
